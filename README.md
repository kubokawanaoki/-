## Works

### オンラインクイズアプリ

複数人でオンライン対戦ができるWebクイズアプリを制作しました。

#### 主な機能

* ユーザー登録・ログイン
* ユーザー情報の管理
* クイズルームの作成・参加
* 複数人でのオンライン対戦
* Firestoreを利用したデータ管理
* クイズへの回答

#### 使用技術

* Python
* Firebase Authentication
* Firestore
* HTML
* CSS
* JavaScript

#### 工夫したこと

Firestoreを利用してユーザー情報やルーム情報を管理し、複数のユーザーが同じクイズルームに参加できる仕組みを実装しました。

また、Firebaseの権限設定によるエラーが発生した際には、原因を調べながら設定を見直し、問題を解決しました。
